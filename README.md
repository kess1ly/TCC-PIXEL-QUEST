# PIXEL QUEST 

O PIXEL QUEST é um projeto desenvolvido como Trabalho de Conclusão de Curso do Técnico em Desenvolvimento de Sistemas.

A proposta é criar uma plataforma educacional gamificada para ensinar lógica de programação de maneira interativa e divertida.

## Objetivo

Proporcionar aos usuários uma experiência de aprendizagem por meio de aulas, exercícios e missões.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
