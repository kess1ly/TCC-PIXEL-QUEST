# Aplicação

Representa a integração entre o front-end, o back-end e o banco de dados do PIXEL QUEST.

Quando o jogador realiza uma ação, o front-end envia as informações ao back-end por meio da Fetch API. O PHP valida os dados, aplica as regras necessárias e, quando necessário, consulta ou atualiza o MySQL. Em seguida, retorna uma resposta para a interface.

A aplicação deverá funcionar de maneira integrada, permitindo a comunicação entre suas diferentes camadas.
