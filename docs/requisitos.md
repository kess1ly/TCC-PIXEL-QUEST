# Requisitos do PIXEL QUEST

## Objetivo do sistema

Desenvolver uma plataforma educacional gamificada para ensinar lógica de programação por meio de aulas, exercícios e missões.

## Requisitos funcionais

- RF01 – Permitir o cadastro de usuários.
- RF02 – Permitir o login e logout.
- RF03 – Disponibilizar aulas de lógica de programação.
- RF04 – Apresentar exercícios práticos.
- RF05 – Disponibilizar missões e desafios.
- RF06 – Registrar a pontuação e os níveis dos usuários.
- RF07 – Permitir o acompanhamento do progresso.
- RF08 – Disponibilizar conquistas e medalhas.
- RF09 – Permitir que administradores gerenciem os conteúdos.

## Requisitos não funcionais

- RNF01 – Apresentar uma interface intuitiva e organizada.
- RNF02 – Proteger os dados dos usuários.
- RNF03 – Utilizar banco de dados MySQL.
- RNF04 – Validar os dados enviados pelos usuários.
- RNF05 – Ser compatível com navegadores modernos.
